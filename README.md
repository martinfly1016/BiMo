# 笔墨 BIMO · 毛笔物理书写工作台

模拟真实毛笔书写过程的网页工作台：一方面建立基于真实物理特性的毛笔原型，另一方面用"拟人"的笔法脚本（藏锋、顿笔、提按、回锋、出锋）演示书法书写技巧——阶段性目标是复现样例视频中楷书"永"字的书写全过程（永字八法）。

## 运行

```bash
python3 -m http.server 8642
# 打开 http://localhost:8642
```

（纯静态页面，无构建步骤；任何静态服务器均可。）

## 毛笔物理模型

参照真实毛笔的三个子系统（参考物理毛笔仿真文献中的 geometry / dynamics / ink 三分法）：

1. **笔锋动力学**——笔杆带动笔锋，笔锋以弹簧-阻尼方式跟随；压力越大、纸面摩擦越大，笔锋拖行越沉。锋尖轨迹天然滞后于笔杆，这是"中锋用笔、锋在画中"的物理来源；提笔时接触区收缩回锋尖，自然形成出锋收尖。
2. **铺毫足迹**——接触区为泪滴形（锋尖窄、笔腹圆），压力（提按）决定铺毫宽度与接触长度。湿墨时画实心足迹（边缘干净），墨枯时实心淡出、离散笔毫接管。
3. **墨模型**——笔含一池墨，随铺毫扫过的面积消耗；每根笔毫有独立储墨差异，墨枯或行笔过快时部分笔毫断供，形成**飞白**；顿笔驻留处墨自然累积加深。

## 笔法脚本（拟人书写）

每个笔画是一串关键节点 `{x, y, p, v, dwell}`（位置 / 压力 / 速度倍率 / 驻笔时长），用 Catmull-Rom 样条插值行笔轨迹，压力用平滑步过渡。人的技巧被直接编码为节奏模式：

- **藏锋逆入**：起笔前一小段反方向、零压力的空中动作（欲右先左）
- **顿笔**：`dwell > 0` 且压力抬升，墨在驻留处累积
- **中锋行笔**：中段压力平稳、速度均匀
- **回锋收笔**：末尾反向低压小段（点、横末）
- **出锋**：压力快速归零同时加速（撇尾、捺尾、趯钩）

「永」字八法对应：侧(点)、勒(横)、努(竖)、趯(钩)、策(仰横)、掠(长撇)、啄(短撇)、磔(捺)。

## 工作台功能

- ▶ 一键书写「永」字全程演示，或逐笔回放八法各笔并显示笔法要领
- 毛笔参数：笔锋大小、笔毫弹性（软毫/硬毫）、含墨量（蘸墨）、墨色（朱砂红/墨黑）
- 纸张参数：吸墨/洇墨程度、米字格开关
- 手写模式：鼠标/触控笔直接书写；触控笔用真实压感，鼠标以运笔快慢模拟提按
